> **Окончателна геометрия имат само изградените страници** (към момента Home, За компании, Как работи Genki и Мисия). Всичко останало е provisional и се уточнява след build-а на съответната страница. Не се праща като спецификация на доставчик, преди страницата да съществува.

## РЕГИСТЪР НА ASSET ID — ЗАКЛЮЧЕН 2026-09-19

Каноничната **VISUAL ASSET MAP** от „GENKI 2.0 — WEBSITE COPY & HANDOFF" е схемата. Разминаването с по-ранния numbering в `GENKI-2.0-ASSETS.md` е **затворено** — кодът, преводите и този документ са мигрирани.

### Правилото

Asset ID носят **само реални производствени активи**:

- изображение
- видео
- изрязан хардуер
- продуктов packshot
- визуал, доставен отвън
- генериран визуал
- реален UI визуал, когато се държи като актив

**UI компоненти, типографски блокове и CSS визуални системи НЕ консумират asset ID.**

Причината е, че тези ID-та живеят извън кода: имена на файлове, заявки към доставчици, комуникация с MAIKOZ, shot листи за фотосесия, брифове за генериране, папки с активи и проследяване на производството. **Един ID никога не може да значи две различни неща.**

Следствие: ID, който каноничната карта дефинира, но текущата имплементация покрива с компонент, **остава запазен и неизползван**. Не се преназначава на нещо друго.

### ⚠ Предложение: G07 — лога на производителите

Каноничната карта **няма** слот за логата на българските производители. Те обаче са реален външно доставен визуален актив: нужни са файлове, нужно е писмено разрешение и се появяват на две страници (Home и Мисия).

Предлагам **G07 — Producer logo set**. Не го въвеждам като факт: в кода лентата е компонент с placeholder-и и **не консумира ID**, докато няма одобрение.

Алтернатива: да влязат под **G03** (продуктови packshots), но това смесва опаковки с лога и връща двусмислието, което току-що затворихме.

## Как се четат ID-тата

Дългите семантични имена (`HOME-HERO-01`) са **описателни псевдоними** за разговор и за prompt. Не заместват ID-то никъде — в кода, във файловите имена и в заявките към доставчици стои краткото ID.

## Категории източник

| Код | Източник |
| --- | --- |
| **A** | MAIKOZ / Instant Systems |
| **B** | Собствена фотография на Genki |
| **C** | Снимки, предоставени от български производител |
| **D** | Генериран актив (Цветелин + ChatGPT) |
| **E** | UI, рендиран от реален интерфейс/код |
| **F** | Съществуващ одобрен Genki актив |

| **H** | Неопределено |

## Приоритет

- **P0** — без него сайтът не се публикува.
- **P1** — важно, но не спира публикуването.
- **P2** — по желание, добавя се след launch.

# Файлов стандарт

## Мастер срещу web

| Ниво | Формат |
| --- | --- |
| **Мастер** (извън репото) | RAW, TIFF или JPG с максимално качество. PNG с прозрачност за изрязани обекти. |
| **Web доставка** (в репото) | WebP основно, AVIF където има смисъл, JPG fallback, PNG само при нужда от прозрачност |

**Не искаме от MAIKOZ предварително компресирани за web файлове, ако могат да дадат оригинали.** Компресията е наша работа — от оригинала се правят трите ширини за `srcset`.

## Именуване

```
<id>-<кратко-описание>-<вариант>.<формат>
```

```
h01-cooler-office-desktop.webp
h01-cooler-office-mobile.webp
h06-products-table-desktop.webp
w02-card-tap-nexgo.webp
f04-cooler-700-single-cutout.png
```

ID-то винаги е първо, винаги с малки букви.

## Папки

```
assets/img/<страница>/        home · companies · works · mission · fit · global
```

Мастерите стоят **извън репото**, за да не тежи с 40 MB TIFF-ове.
