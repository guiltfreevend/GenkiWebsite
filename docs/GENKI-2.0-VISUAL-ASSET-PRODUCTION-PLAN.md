## Как се четат ID-тата

`H01`, `C01`, `W02`, `F04` са **каноничните implementation ID-та** — те стоят в кода, в имената на файловете и в `GENKI-2.0-ASSETS.md`.

# Файлов стандарт

## Мастер срещу web

| Ниво | Формат |
| --- | --- |
| **Мастер** (извън репото) | RAW, TIFF или JPG с максимално качество. PNG с прозрачност за изрязани обекти. |
| **Web доставка** (в репото) | WebP основно, AVIF където има смисъл, JPG fallback, PNG само при нужда от прозрачност |

**Не искаме от MAIKOZ предварително компресирани за web файлове, ако могат да дадат оригинали.** Компресията е наша работа — от оригинала се правят трите ширини за `srcset`.

## Именуване

```
<id>-<кратко-описание>-<вариант>.<формат>
```

```
h01-cooler-office-desktop.webp
h01-cooler-office-mobile.webp
h06-products-table-desktop.webp
w02-card-tap-nexgo.webp
f04-cooler-700-single-cutout.png
```

ID-то винаги е първо, винаги с малки букви.

## Папки

```
assets/img/<страница>/        home · companies · works · mission · fit · global
```

Мастерите стоят **извън репото**, за да не тежи с 40 MB TIFF-ове.
