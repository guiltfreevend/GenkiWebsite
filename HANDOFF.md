# Genki 2.0 — Handoff

## Къде сме
**Етап 1.5 — Калибриране на основата по DESIGN-DIRECTION: ЗАВЪРШЕН (2026-09-19).** Следващ: Етап 2 — Начало (Home). Чака преглед на етапа.

Целият план, чеклистите по етапи и подробният отчет за етап 1 са в `docs/BUILD-PLAN.md`. Това е файлът, от който се разбира докъде сме стигнали.

## Клон
Работи се в `genki-2.0-build`. `main` остава непокътнат и обслужва живия сайт до cut-over.

## Какво е готово
- **Design tokens** — `css/genki-tokens.css`. Брандовото зелено е `#1d5329` (измерено от логото), акцентът `#218336`. `#2d8659` е отменено. Скалата е калибрирана срещу `docs/DESIGN-DIRECTION.md` и проверена на 8 ширини.
- **12-колонен grid** (12 / 8 / 4), редакционна типографска скала с роли, нова радиус система, motion примитиви.
- **Без Tailwind** — 407 KB JS по-малко на страница. Стиловете са чист CSS върху токени.
- **Скелет на 6-те страници** в `v2/` — Начало, За компании, Как работи, Мисия и въздействие, Genki Fit, Контакт.
- **Хедър, мобилно меню, BG/EN превключвател, футър** — един източник в `tools/partials/`, синхронизира се с `node tools/sync-partials.js`.
- **VisualSlot** `<genki-slot slot-id="H01">` — точните съотношения, alt на двата езика, `<picture>` API за отделни desktop/mobile кадри, override на съотношението за композиция.

## Как се тества локално
```
python -m http.server 8765
```
после `http://localhost:8765/v2/index.html`

След промяна в хедъра или футъра:
```
node tools/sync-partials.js          # преписва партиалите в 6-те страници
node tools/sync-partials.js --check  # проверява без да пише
```
